## 4. `cj` 当前只冻结为 collision / adjacency radius

现有字节码：

```text

```

已经足够证明 `cj` 是实体邻接/碰撞几何中的半径字段。

因此可以命名：

```text

```

但暂时不要命名为：


```text

```

写进最终 engagement candidate 公式。

必须等真正的攻击距离判定链确认后再组合。

## 5. “<185”只能作为 consistency filter

《对话23》当前计划里：

> 若某字段 <185，则为射程的有力候选。

请收紧措辞。

本局事实：

```text
最近单位距离约185
seaFactory约51秒零伤害
```

只能说明某些数值与“射程小于该距离”**一致**。

不能把：

```text
fieldValue < 185
```

当作强正证据，因为：

* 大量无关 float 也可能小于185；
* 185不是必然的 target-edge 距离；
* `cj` 已经证明实体存在半径；
* 零伤害也可能首先来自移动域/站位问题。

因此命名为：

```text
RANGE_CONSISTENT_CANDIDATE
```

或仅作为排除/筛选条件。

真正的射程确认仍优先来自：

```text
attack distance comparison bytecode trace
```
