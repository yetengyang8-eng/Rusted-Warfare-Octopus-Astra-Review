# Public mirror scope

This repository is a public-safe mirror of the engineering workspace, not a byte-for-byte dump of `G:\deepseek 工作台`.

Excluded on purpose:

- Vanilla Rusted Warfare executables, JARs, DLLs, JVM bundle, fonts and assets
- Save games and `.replay` files
- Full raw report archives and temporary/headless run directories
- Third-party GitHub repository mirrors already available from their original upstreams
- Community documents whose redistribution terms were not established
- Private/internal chat transcripts (`对话*.txt`, `输出*.txt`) and similar conversation dumps
- Build products, caches, temporary directories and ZIP/RAR archives

Included:

- Project-authored Agent source and tests
- Project-authored tools and documentation
- Current project-state notes
- Selected engineering handoffs and contracts
- Distilled knowledge packet outputs, excluding copied decompiled/source evidence trees
- One Agent-POV tactical viewer example
