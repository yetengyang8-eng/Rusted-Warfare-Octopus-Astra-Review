## 下一局优先观察五件事

1. **小威胁的响应规模**：放一个小骚扰或短暂露脸目标，是否仍同时拉走多支远处 General。日志看 `COMMANDER_THREAT_BUDGET` 的 demand、localCovered、assigned、deficit 与每队中断成本；敌人消失后是短暂原地注意还是跨图来回。
2. **基地火力圈与强攻时机**：第一次合法发现基地，低战力是否绕开已知防区而不是反复踩入；后续兵力/DPS增加且基地仍当前可见时能否主动攻入。记录看见、被挡、突破的大致游戏时间。隐藏基地只影响旅行候选，不应该出现隐藏攻击。
3. **高收入现金去向**：当普通库存接近112/128后，是否继续生产、扩张库存/投资，是否又全厂空闲。同时看收入、armyTarget、activeTarget、hardSafetyCap、native quote、unsettled/保留预算、producer利用率。不要仅用最高余额判断扩厂成功。
4. **矿升级两条尾链**：有钱时T1/T2/T3能否继续；危险/证据不足地区是否按原版报价选择强化，保守低威胁地区是否保留超频机会。下单、扣钱、队列、产物完成分开看；强化矿不应被记成新增收入。
5. **伤兵回收与再分配**：严重伤兵是否停止旧进攻、前往己方恢复点；规模扩大时是否形成修复湾施工；真正恢复到75%后是否回FREE并重新补员。两栖闲置独立记录，不能视作普通伤兵/普通补员。
