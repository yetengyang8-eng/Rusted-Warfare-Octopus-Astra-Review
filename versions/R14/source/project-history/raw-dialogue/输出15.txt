1. 事实判定

本局 4 次 SECONDARY_INVESTMENT_DEFERRED 时：

secondary=T1，空闲；
upgrade=2000，均买不起；
cheapest combat=c_tank(350)，均买得起；
primary 当时 queue=1/busy；
primaryReserve=0；
所以 credits - 350 >= primaryReserve 四次全部成立。

replay 共找到 7 个 secondary idle tick，其中 cheap combat 均同时满足：

affordable by credits
+
allowed by primary reserve

因此副厂 0 单位产出并非“无 surplus”，而是：

unaffordable secondary upgrade
→ 阻止了 lower-cost legal combat action

这个行为需要修。

2. 修改原则

明确定义：

SECONDARY INVESTMENT
= opportunistic surplus investment
≠ long-term savings target

即：

第二生产者的 upgrade 只有在当前已经可以支付，且支付后不侵犯 primaryReserve时才允许执行。

如果 secondary upgrade 当前不能执行：

upgrade unavailable / unaffordable / violates reserve
↓
SECONDARY_INVESTMENT_DEFERRED
↓
继续检查 lower-cost combat actions

不要立即结束该 factory 的决策。

3. Secondary cheap fallback

对 lower-cost combat action 继续使用：

credits - combatCost >= primaryReserve

成立才允许购买。

因此例如：

primary busy
primaryReserve=0
credits=469
secondary upgrade=2000
secondary c_tank=350

应：

upgrade deferred
→ c_tank allowed

但：

primary idle
primaryReserve=800
credits=1000
c_tank=350

因为：

1000-350 < 800

所以仍然不得购买。

4. 不得影响 Primary Tech

此修正规则只适用于 SECONDARY INVESTMENT。

保持：

唯一/主生产者尚未解锁 mainline
→ PRIMARY_TECH_BANKING

这种真正决定主力科技路线的升级仍允许主动攒钱，不得 fallback 成廉价单位把升级一直拖延。

同样保持：

primary mainline 买不起
→ RESERVED_FOR_PRIMARY_PRODUCTION

主厂仍不得 cheap fallback。

5. 不改变评分体系

不修改当前：

c_tank score 1
heavyTank score 3
upgrade score 5

只改变：

secondary preferred upgrade 当前无法合法执行时，是否允许继续检查 lower-priority legal action。
