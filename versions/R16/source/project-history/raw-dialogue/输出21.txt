## 3. 必须区分三个概念

后续代码和报告里禁止把下面三件事混成一个 boolean：

```text
A. Targetable
   武器/目标类型规则是否允许攻击它

B. PathToTargetCoordinate
   该 movement class 是否能走到 target x/y

C. ReachableEngagementPosition
   是否存在一个攻击者能够走到、并从那里实际进入合法攻击距离的位置
```

我们最终真正需要给 `TARGET_REACHABILITY_GUARD` 使用的是 **C**。

`aq.a(y,am)` / `aq.b(y,am)` 虽然已经确认存在，而且反编译显示它们参与单位—目标判定，但当前还没有实机证据证明它们本身就等价于 C。

因此：

```text
aq.a(y,am) != assumed ReachableEngagementPosition
```

在校准完成以前只能作为一个 raw anchor。

## 4. 先校准 passability / path API 的真实语义

当前 headless probe 的结果存在明显不能直接解释的组合：

```text
(0,0)/(5,5)/(90,90)
gridPassable=false
moveCost=0

(175,175)/(149,153)
gridPassable=true
moveCost=-1
```

而夹具地图只有110×110，并且 per-class 查询因为夹具未完整初始化而报 ERR。

因此目前不能直接冻结：

```text
a(...) true = passable
b(...) -1 = unreachable
```

之类的语义。

下一步实机诊断必须包含 **正负控制**。

### Positive control

找一个正常地面交战中的目标，例如：

```text
heavyTank / c_tank
→ 可正常攻击的 landFactory / turret / ground unit
```

要求记录所有 raw API 返回。

### Negative/cross-domain candidate

如果正常局里再次出现：

```text
LAND attacker
→ seaFactory / island building / water-separated target
```

同样记录所有 raw API 返回。

只有看到：

```text
known engageable case
vs
known non-engageable/stalled case
```

在 API 返回上形成稳定区别，才能开始赋予语义。

## 5. 不要固定使用“目标外1～3格”

《对话21》§3.3 的：

```text
target footprint 外 1~3 tile 环
```

暂不批准作为最终 engagement-position 算法。

因为合法射击位范围应当至少受到：

```text
attacker weapon range
target geometry/radius
tile world size
```

影响。

例如以后火炮可能在远于3格的位置就能攻击。

因此未来 candidate radius 应动态来自类似：

```text
ceil((effectiveWeaponRange + targetRadius) / tileWorldSize)
```

具体公式等真实射程/geometry字段确认后再定。

第一版 raw endpoint 不需要枚举完整射击环。

## 7. diagnostics 应按兵种/代表单位取样，而不是只看一辆坦克

未来 MAIN_FORCE 可能同时包含：

```text
c_tank
heavyTank
artillery
hoverTank
...
```

一个目标可能对某类单位不可接战，但对另一个兵种可接战。

因此实机 diagnostic 建议按当前 active army 中的 combat type 选代表单位，例如：

```text
target seaFactory #229

c_tank representative:
    raw engine results...

heavyTank representative:
    raw engine results...

artillery representative:
    raw engine results...
```

不需要对41辆单位逐个跑昂贵路径查询。

目标是最终能够回答：

```text
0 / N combat types can engage
or
some combat types can engage
```

这会为未来 Task Group / pursuit detachment 提供基础，但本轮仍然不施工分队。

## 10. STALLED_ENGAGEMENT 可以继续作为独立诊断

保留 conservative diagnostic：

```text
same target persists >= T
AND target HP unchanged
AND many attackers converge
AND minimum distance no longer improves
→ STALLED_ENGAGEMENT
```

它不声称知道原因。

可能原因包括：

```text
unreachable domain
path obstruction
weapon incompatibility
range/geometry issue
AI order issue
```

因此：

```text
STALLED_ENGAGEMENT != UNREACHABLE
```

当前 seaFactory 样本已经是非常强的 `STALLED_ENGAGEMENT` 实例。
