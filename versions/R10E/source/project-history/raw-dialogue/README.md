# 原始工程对话流

这里保存用户明确授权公开到项目中转站的工程对话/输出原文，用于让远程 Astra、DeepSeek、Codex 在缺少本机 G: 盘和旧聊天上下文时恢复项目决策过程。

范围仅限 `G:\deepseek 工作台\助手交接` 中与 Rusted Warfare Agent 工程直接相关的 `对话N.txt`、`输出N.txt` 和 `HANDOFF_对话N.md`；没有从用户 ChatGPT 账号抓取其它私人聊天，也不包含本项目以外的个人资料。

使用原则：
- 优先读 `project-state/CURRENT_STATE.md`、当前 handoff 和任务书；不要从旧对话自行覆盖最新结论。
- 原始对话是历史证据，不保证其中的旧假设、版本号、路径或实验结论仍然有效。
- 需要追根因、理解为什么曾作出某个工程选择时，再按编号检索这里。
- 与当前源码/冻结哈希/新证据冲突时，以当前可复核证据为准，并记录冲突。

这些文件约 0.6 MB，保留原文件名和原始文本，方便全文搜索。
