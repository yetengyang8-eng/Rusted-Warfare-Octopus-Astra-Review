### 3.1 引擎侧可用的 API（javap 反汇编 + headless 实测）

| 层 | API | 作用 |
| --- | --- | --- |
| 移动类别 | `com.corrodinggames.rts.game.units.ao`（enum） | `NONE / LAND / BUILDING / AIR / WATER / HOVER / OVER_CLIFF / OVER_CLIFF_WATER`；地面单位 = **LAND**（实测 `engine.bU.z.a == LAND`） |
| 寻路器 | `com.corrodinggames.rts.gameFramework.k.l`（`engine.bU`） | `k.i a(ao)` 取该类别通行网格；`boolean a(k.i,int,int)` 可通行；`int b(k.i,int,int)` 移动代价（−1 = 不可通行）；`boolean a(int,int)` 全局可通行；`boolean a(ao,int,int)` 按类别查询 |
| **单位级可达性** | `com.corrodinggames.rts.game.units.aq` | **`boolean a(ao, float fromX, float fromY, float toX, float toY, int, int, int)`——取该类别网格后发起真实可达性/代价查询**；`boolean b(...)` 同签名变体；`PointF a(ao,...,boolean)` 返回路径点 |
| **攻击可达判定** | `aq` | **`boolean a(y unit, am target)` / `boolean b(y unit, am target)`** —— 这正是引擎自己用来判定"这个单位能不能打到那个目标"的函数（bytecode 里先 `y.k(target)` 再 `target.d(attacker)`） |
| 桥接挂点 | `CombatBridge` | 已经通过反射持有活的 `am` 单位与世界对象（`capabilities()` 就是这么读 boolean 字段的），**不需要新的注入通道** |

tile 编号 = `y * height + x`，与 `search_target` 事件里的 tile 同一坐标系。

### 3.3 最小实现方案（等待你的批准，本轮未写）

新增一个**只读**桥接端点（不改战术）：

```text
GET /combat/reachability?unitId=<id>&targetId=<enemyId>
→ {
    "unitMovementClass": "LAND",
    "targetMovementClass": ..., "targetBuilding": true,
    "targetFootprintTiles": [...],                  // 目标占地格（引擎几何）
    "attackerRangeWorld": ...,                      // 实机读取的武器射程
    "engagementCandidates": N,                      // 目标周边候选射击位数量
    "passableCandidates": N,                        // 其中对攻击者可通行的
    "pathReachableCandidates": N,                   // 其中路径可达的
    "reachableEngagementPosition": true|false,      // ← 直接事实
    "nearestReachableDistanceWorld": ...,           // 到最近可达射击位的距离
    "engineAttackReachability": true|false          // aq.a(y,am) 的原生判定
  }
```

实现路径（不新造寻路系统）：

1. 取目标占地格与半径（引擎几何 / 目标 `am` 的 `bI()`/尺寸字段）；
2. 在占地外 1~3 格环上枚举候选格，过滤 `k.l.a(grid, tx, ty)` 可通行；
3. 对通过过滤的候选格调用 `aq.a(movementClass, fromX, fromY, candX, candY, ..., budget)` 判断路径可达；
4. 再按攻击者武器射程过滤 → 得到 `reachableEngagementPosition`；
5. 与 `aq.a(y, am)` 的原生攻击可达判定交叉验证。

**备选 conservative detector（你给的 fallback，不冒充真实可达性）**：同一目标持续 ≥T + HP 不变 + 多攻击者汇聚 + 最小距离停止改善 → `STALLED_ENGAGEMENT`。本局数据已经完全满足这四条（T ≈ 51s、HP 恒 1000、41 个攻击者、min 距离停在 185）。

`TARGET_REACHABILITY_GUARD` **仍未施工**，等 §3.3 落地并取到直接事实后再定 v0。
