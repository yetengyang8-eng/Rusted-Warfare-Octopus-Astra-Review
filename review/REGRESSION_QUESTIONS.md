## 先检验以下问题

1. **地面接近基地时的新局部评估是否把非敌防空目标/其他廉价目标附近的基地圈当作不可逾越障碍？** 是否发生反复STANDOFF↔frontier、可聚拢却无法推进？
2. **以附近400半径兵力估算可战能力是否过度排除正在高速接近/正在协同的有效分队？** 该半径是现有编组几何参数，不应用同一尺度冒充敌方所有攻击范围。
3. **Builder远端区域保护是否造成本土repair/资本设施补工不足？** 有无真实新工人到达、实际建成 vs 仅有建造Intent？
4. **地面受限时，Air原始任务、重获视野和清剿是否得到不同的世界状态与可用支持？** Air代码不变但外部前线/经济/目标可见性可能改变。
5. **后期305架两栖却没有胜利，问题出在目标数量/寻敌、绕防空、无实际attack accepted、长距离支援，还是敌人仍剩水下/不可达残余？** 必须关联 R16 原生Raw，同时间坐标与命令。
6. **是否把原本健康的多分队补兵变成更长距离的跨图迁徙？** 对照真人1v9的分散集团只能提供启发，不能直接证明最优。
7. R16 当前有三项本地 dirty 工具文件，它们**未并入任何冻结源码快照**。不要无意将它们并入新版本；若对运行工具有影响，分别报告环境差异和实际使用工具SHA。

## 必须保护的控制约束

- G0～G6 真实 Bridge / fog / generation / ABA / owner / receipt 守卫不可旁路。
- 不接受 phantom native attack；记忆位置只用作合法搜索和预警。
- 不用静态编队数量、固定存钱时间、死阈值盲修。
- 首先做 R15 / R16 差异定位与有效原生局复现，改动最小且隔离；大规模重构需要独立证据。
